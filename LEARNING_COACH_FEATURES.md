# Learner Companion · New features

Built-in, no API required:
- Daily goal, activity streak and earned achievement badges (locally tracked).
- Skill-level spaced review queue with Again / Good / Easy ratings, adaptive intervals, and suggested answers.
- Bookmark any page and save page-specific notes.
- Review skills from all five courses using Save for review.
- Export and import local learner progress as JSON.
- Accessible keyboard controls and responsive UI.

Inspired by the public descriptions of mastery learning at Khan Academy and habit goals/streaks at Duolingo. Not affiliated. This feature is self-reported, not independently graded; browser localStorage is device-specific. Instructor-certified course status remains separate.

Offline AI Tutor is a curated local reference system, not a generative model. Existing hosted authentication and Supabase features may still require network access even though the companion requires no AI API.
