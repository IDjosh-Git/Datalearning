# Foundation roadmap and course alignment audit — 1 November 2026

## Scope

- **Introduction to Data Analysis player** (`courses/introduction.html`): Foundation Roadmap lesson-selector, generated by `assets/scripts/weekly-workspace.js`.
- **Standalone course roadmap** (`courses/introduction-roadmap.html`): milestone cards, lesson list and preparation guidance.
- **Your Course at a Glance**: generated across the six course tracks by `assets/scripts/learning-catalog.js`.

## Implemented

1. Removed the foundation roadmap's two *horizontal-scrolling arrow buttons and their event handler* from generated markup. **Previous/Next lesson buttons remain**, because they change the active lesson and are not the redundant scroll arrows.
2. Converted the foundation step selector to a spacious 2-, 3- or 4-column desktop grid according to viewport width, retaining a swipeable horizontal strip on narrow screens.
3. Matched foundation guide, progress summary, resources, hero and lesson content to the same responsive maximum width, removing unnecessary blank desktop margins.
4. Kept the existing `intro-side` anchor navigation in source for event compatibility, but hide it only when the interactive foundation roadmap has initialized, avoiding two visible outlines.
5. Aligned headings, count summary, progress meter and next-lesson link inside **Your Course at a Glance**. Standardised its outer width for all six course pages, with a readable mobile stack.
6. Made the separate Introduction Roadmap wider, with consistent milestone and lesson-list grids and text wrapping.
7. Updated course canvas text colours to the current ink/navy/slate palette and bumped the public offline cache namespace.

## Preserved

- Lesson count, lesson content, selected/current lesson states, progress checkboxes and synchronization.
- Previous and Next lesson controls, lesson dropdown, direct hash navigation, mastery checkpoint and downloaded resources.
- Public course access, account sign-in for personal progress and protected administration.

## Verification and limits

- Added `tests/foundation-roadmap-alignment.mjs` to responsive suite.
- Existing build, lint, and full test suite were run after implementation.
- Browser rendering may still require a deployment-level inspection; static tests alone cannot prove there is no viewport overflow.
