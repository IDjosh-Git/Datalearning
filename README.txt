Data Analysis Learning Path — Manual Capstone Grading Edition

Start at index.html after deploying to Vercel. Learn from the full Introduction, Excel, SQL and Power BI courses. The Capstone Studio accepts photos/screenshots and supporting files. Your private reviewer.html dashboard lets you inspect learner submissions and manually score their work.

Setup:
1. Run updated supabase_setup.sql in your CURRENT Supabase learning project.
2. Copy your owner account's Auth UID into OWNER_SETUP.sql and run it.
3. Deploy the complete project to Vercel. Check that Data API exposes public and api schemas.
4. Sign in as owner, open account.html and click Instructor review desk.

New assessment scores and written feedback appear only when you click Publish. A score of 70 or more issues the completion certificate immediately. No AI reviewer, scheduled grading job or five-day release wait.

Full instructions: README.md and CLOUD_SETUP_STEP_BY_STEP.md.
