Week 5: Filtering, grouping and business KPI calculations

Learning outcome: Compute revenue, customer counts and category KPIs with pandas using explicit business rules.

Estimated time: Not verified.

Hands-on task · practice: Build a region summary with paid revenue and distinct orders, then identify top contribution.

Activity type: Practice (completion requirement not verified); knowledge check is a self-check. Assessment status is not confirmed.

Success criteria (practice guidance, not a grading rubric): Produce the requested output, explain how it was obtained, check it against the example and identify one possible error or limitation.

Hint: where to start

Using count instead of nunique for order IDs or including returned orders in paid sales.

Worked example and explanation (open after trying)
import pandas as pd
df=pd.read_csv('learning_sales_quality_lab.csv')
df['quantity']=pd.to_numeric(df['quantity'],errors='coerce')
df['unit_price_ngn']=pd.to_numeric(df['unit_price_ngn'],errors='coerce')
# Flag invalid numeric fields; exclude them from the calculation, never silently repair.
invalid=df['quantity'].isna()|df['unit_price_ngn'].isna()
print('Rows needing investigation:',int(invalid.sum()))
valid=df.loc[~invalid].copy()
valid['revenue_ngn']=valid['quantity']*valid['unit_price_ngn']
completed=valid.loc[valid['status'].eq('Completed')]
summary=completed.groupby('region',dropna=False).agg(
    revenue_ngn=('revenue_ngn','sum'),orders=('order_id','nunique'))
print(summary)

The sum of grouped paid revenue must match the source Paid-only revenue under the same filters.

Hint: where to start

Using a many-to-many join and then treating inflated Revenue as genuine growth.

Worked example and explanation (open after trying)
import pandas as pd
monthly=pd.read_csv('learning_monthly_kpis.csv')
targets=monthly[['month','region','sales_target_ngn']].drop_duplicates()
facts=monthly.drop(columns='sales_target_ngn')
report=facts.merge(targets,on=['month','region'],how='left',validate='many_to_one')
report['target_attainment']=report['net_sales_ngn']/report['sales_target_ngn']
print(report[['month','region','target_attainment']].head())

Post-merge row count must equal source orders for a valid many-to-one join; unmatched categories must be counted.
