Hint: where to start

Worked example and explanation (open after trying)
Business example: A retailer needs comparable regional KPIs before creating a dashboard in a BI tool. Worked solution or syntax:
SELECT region,COUNT(DISTINCT order_id) AS orders,
ROUND(SUM(quantity*unit_price*(1-discount_pct)),2) AS net_revenue
FROM orders WHERE status='Completed' GROUP BY region ORDER BY net_revenue DESC;

Sum of regions must reconcile to the Completed-only grand total unless intentionally excluded by HAVING.

Business example: A merchandising team needs product categories to compare profitability without losing orders with missing reference values. Worked solution or syntax:

LEFT JOIN should keep every source order row if the product dimension is unique; totals should remain unchanged.

Worked example and explanation (open after trying)
Business example: An analytics engineer is preparing a report query colleagues must be able to read and audit. Worked solution or syntax:
WITH completed AS (SELECT * FROM orders WHERE status='Completed'),
regions AS (SELECT region,SUM(quantity*unit_price*(1-discount_pct)) AS total
FROM completed GROUP BY region)
SELECT * FROM regions ORDER BY total DESC;

The sum of regions should equal the Completed-only sum from the base table, with matching date ranges.

Week 7: Window functions and time-based comparisons

Learning outcome: Calculate rankings, running totals and period comparisons without losing transaction detail.

Estimated time: Not verified.

Hands-on task · practice: Find the last month versus current month change for each region and create a running-revenue result.

Activity type: Practice (completion requirement not verified); knowledge check is a self-check. Assessment status is not confirmed.

Success criteria (practice guidance, not a grading rubric): Produce the requested output, explain how it was obtained, check it against the example and identify one possible error or limitation.

Hint: where to start

Omitting ORDER BY inside an ordered window and interpreting undefined sequence as time.

Worked example and explanation (open after trying)
Business example: The operations team requests a monthly comparison table to feed a line chart and exception report. Worked solution or syntax:
WITH monthly AS (
 SELECT region,substr(order_date,1,7) AS month,
 ROUND(SUM(quantity*unit_price*(1-discount_pct)),2) AS revenue
 FROM orders WHERE status='Completed' GROUP BY region,substr(order_date,1,7)
)
SELECT region,month,revenue,
LAG(revenue) OVER(PARTITION BY region ORDER BY month) AS prev_revenue,
SUM(revenue) OVER(PARTITION BY region ORDER BY month) AS running_revenue
FROM monthly ORDER BY region,month;

For values 10,15,12 by month, running total is 10,25,37; first LAG is NULL.

Worked example and explanation (open after trying)
Business example: A Power BI team needs a trustworthy monthly fact table to build a management dashboard. Worked solution or syntax:
SELECT substr(order_date,1,7) AS month,region,
ROUND(SUM(quantity*unit_price*(1-discount_pct)),2) AS completed_revenue,
COUNT(DISTINCT order_id) AS order_count
FROM orders WHERE status='Completed'
GROUP BY substr(order_date,1,7),region ORDER BY month,region;

Every row represents one month-region combination; when grouped again by month, totals must reconcile.
