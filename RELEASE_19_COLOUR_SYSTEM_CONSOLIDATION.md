# Release 19 — Colour system consolidation

- Consolidated semantic colour contracts in the shared premium and runtime layers.
- Replaced legacy fixed footer colours with live brand tokens; removed fixed old colours from the Admin Appearance form.
- Standardised cross-page headers, cards, form borders, focus indicators, primary actions, and semantic error colours.
- Preserved the four editable Admin Appearance colours and the server-backed branding runtime.
- Scope: source-level consolidation and automated contrast checks; not a claim of full visual WCAG compliance or complete removal of every historical token in all legacy stylesheets.
- Not deployed to Vercel.
