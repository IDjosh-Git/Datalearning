# Offline teaching upgrade — 21 October 2026

- Formula library expanded from 54 to 103 searchable examples across Excel, SQL, DAX and Power Query. Includes definitions, working patterns, cautions, levels and copy buttons.
- Offline lesson engine with 115 indexed question/answer teaching records (12 foundational lessons and 103 formula-centered lessons).
- Clear structured responses: explanation, practical code where applicable, practice task and common pitfalls.
- Multiple-choice knowledge checks, progressive hint, immediate explanatory feedback, studied-topic count, attempt accuracy and streak.
- Learner progress is stored in browser localStorage and can be cleared. No API key, network calls or paid model required.
- The tutor is a curated, deterministic retrieval tutor, **not** a generative language model. It cannot reliably solve arbitrary unseen questions; unsupported requests are acknowledged instead of hallucinated.
- Other app features and optional account/cloud functionality were not changed. For complete offline access to the entire app, additional cloud features need separate treatment.
- Teaching techniques informed by Microsoft Learn modular paths and Khan Academy hint-plus-rationale practice.
