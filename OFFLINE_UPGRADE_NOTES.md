# Enhanced offline learning release

- 559 tutor lessons and question-answer cards; 603 formula/query reference entries.
- Learning Lab: search, subject filter, review queue, confidence-based spaced review, mastery progress and local storage.
- Fully browser-based tutor and Learning Lab; no AI API calls.
- Data examples use illustrative Orders schemas. Field names must be adapted to a real data model.
- Learning design inspiration: Microsoft Learn modular paths, Khan Academy mastery and Duolingo daily habit/review patterns.
- Important: this is curated teaching content and retrieval, not a general-purpose language model.
- Open index.html locally or serve using any static web server.
