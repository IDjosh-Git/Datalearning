How to use prompts effectively

Copy a prompt, replace the [BRACKETED FIELDS] with your own approved schema and objective, and test the output in your actual analytics tool.

01

Define the goal

State your business question, dataset grain, time window, metric definition and exclusions.

02

Customize the prompt

Supply column names and approved sample information. Never paste secrets or unauthorized customer data.

03

Execute, don't assume

Run generated formulas, SQL, Python or DAX in the relevant tool; check source totals and edge cases.

04

Record what changed

Save successful prompts, corrections and execution evidence so someone else can reproduce the work.

Tip: Work with the fictional retail practice dataset, or use your organisation's approved data-access process. Tool interfaces and paid features change; prompts focus on transferable techniques.
