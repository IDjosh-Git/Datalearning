About your practice

Attempts, drafts and passed-challenge status are stored locally on this device. Do not expect them to appear on another device or account.

Execution is not the same as passing

A query or formula can run successfully and still fail the challenge checks. Python checks run in a browser worker; its runtime must download first.

Privacy first

Use only the bundled, fictional sample data. Do not paste passwords, personal customer records or production data into the editors.

Execution scope: common Excel formulas are calculated directly with an offline evaluator; advanced SQL runs against SQLite in your browser when its engine loads. Basic SQL exercises remain available offline. SQLite supports SELECT, joins, CTEs, window functions, and more, but is not the same as every database dialect. The spreadsheet evaluator covers many common Excel functions, not every Excel function. Challenge grades use visible and varied hidden datasets; a valid query or formula can run correctly without passing a particular challenge.
