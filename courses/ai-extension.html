Curriculum extension · practical proficiency

Applied mastery: AI

Work through the units in order. Each includes a measurable objective, realistic case, reproducible example and an evidence-based checkpoint. These supplemental exercises do not replace the existing quizzes or graded progress.

Applied unit 1

Frame safe, measurable AI tasks

Learning objectives

Define outcomes, inputs, constraints, and evaluation criteria; identify sensitive data.

Workplace use case

Draft an assistant that summarizes anonymized customer feedback.

Guided practice

  1. Specify task
  2. remove identifiers
  3. write prompts with scope and examples
  4. define an evaluation rubric.

Worked example

Task: Summarize the feedback in 3 bullets.
Rules: Use only supplied text; do not infer demographics.
Output: issue, evidence, suggested next step.

Assessment checkpoint

What should happen when source material is missing? Provide two refusal/uncertainty examples.

Applied unit 2

Test prompts systematically

Learning objectives

Compare prompt variants using fixed evaluation examples; avoid judging by one response.

Workplace use case

Assess a classification prompt on a 20-row labeled dataset.

Guided practice

  1. Create labeled cases
  2. run same input set on each variant
  3. calculate precision/recall
  4. inspect errors.

Worked example

precision = true_positives / (true_positives + false_positives)
recall = true_positives / (true_positives + false_negatives)

Assessment checkpoint

Identify a false positive and document a targeted prompt improvement.

Applied unit 3

Build an accountable AI workflow

Learning objectives

Explain human review, grounding, privacy, and escalation for uncertain answers.

Workplace use case

Design a retrieval-based knowledge assistant for internal policy FAQs.

Guided practice

  1. Choose approved sources
  2. retrieve relevant passages
  3. cite sources
  4. log confidence/fallback
  5. human approval.

Worked example

If no relevant passage is retrieved:
  respond "I cannot verify this from the available sources."
  route to a human reviewer.

Assessment checkpoint

Demonstrate three adversarial inputs and explain the guardrails used.
