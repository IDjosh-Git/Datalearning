Excel Foundations & Navigation

Understand the Excel workspace and become comfortable moving around a workbook.

Beginner

1. Understanding Excel

Learn the basic building blocks.

  • A workbook is the Excel file.
  • A worksheet is a sheet inside a workbook.
  • Rows run horizontally and use numbers; columns run vertically and use letters.
  • A cell is identified by column + row, such as B5.
  • A range is a group of cells, such as A1:D20.

2. Excel Interface

  • Ribbon tabs: Home, Insert, Page Layout, Formulas, Data, Review, View.
  • Formula Bar for viewing or editing values and formulas.
  • Name Box for seeing the active cell or jumping to a location.
  • Sheet tabs for moving between worksheets.
  • Status Bar for quick Sum, Average, and Count.

3. Navigation & Selection

  • Select a cell, row, column, or block of data.
  • Use Ctrl + Home to return to A1.
  • Use Ctrl + End to move toward the last used cell.
  • Use Ctrl + Arrow to move quickly through a data region.
  • Use Ctrl + Shift + Arrow to select a large range.

4. Managing Workbooks & Sheets

  • Create, save, close, and reopen a workbook.
  • Rename, insert, move, copy, colour, and delete worksheets.
  • Difference between .xlsx and .csv.
  • Use Save As to create another version of a file.

Session 1 • 60–75 minutes
Understanding the Excel Environment
Explain it simply: Think of Excel as a digital exercise book. The whole file is the workbook. Each page inside it is a worksheet. Every small box is a cell.
Step by step
  1. Open Excel and create a Blank Workbook.
  2. Point to the column letters A, B, C and explain that columns run from top to bottom.
  3. Point to row numbers 1, 2, 3 and explain that rows run from left to right.
  4. Click cell B4. Explain that B is the column and 4 is the row.
  5. Type Sales into B4 and press Enter. Show that the active cell moves to the next row.
  6. Click the Formula Bar and show that the same value in the active cell appears there.
  7. Click the Name Box, type H20, and press Enter to jump directly to that cell.
Worked example: If a learner is told “enter 2500 in D8”, they should first find column D, then row 8, and type 2500 in the cell where both meet.
What learners should remember
  • Workbook = file.
  • Worksheet = sheet inside the file.
  • Cell = one box.
  • Range = many cells selected together, for example A1:D10.

Formulas, References & Essential Functions

Use Excel to calculate results instead of calculating manually.

Formulas

1. Formula Fundamentals

  • Every formula starts with =.
  • Operators: +, -, *, /, ^.
  • Understand Excel order of operations.
  • Use brackets to control calculation order.
  • Copy formulas using the Fill Handle.

2. Cell References

  • Relative reference: A1.
  • Absolute reference: $A$1.
  • Mixed references: A$1 and $A1.
  • Use F4 to cycle through reference types while editing a formula.

3. Essential Functions

  • SUM, AVERAGE, MIN, MAX.
  • COUNT and COUNTA.
  • ROUND.
  • Example: =SUM(E2:E100).

4. Business Calculations

  • Revenue = Quantity × Unit Price.
  • Profit = Revenue − Cost.
  • Margin % = Profit ÷ Revenue.
  • Discounted Price = Price × (1 − Discount%).
  • Lock a tax or target cell with an absolute reference.

🎯 Week Goal

Write formulas confidently and know why some references move while others stay fixed.

Detailed Learning Sessions

Week 3 introduces formulas. Learners should understand the logic of a formula before memorising functions.

Session 1 • 75 minutes
How Excel Formulas Work
Explain it simply: A formula is an instruction you give Excel. Instead of typing the answer, you tell Excel how to calculate the answer.
Start with simple calculations
  • =10+5 returns 15.
  • =20-7 returns 13.
  • =6*4 returns 24.
  • =100/4 returns 25.
Move from numbers to cell references
  1. Put Quantity in C2 and Unit Price in D2.
  2. In E2 type =C2*D2.
  3. Press Enter.
  4. Drag the fill handle down to copy the formula to other rows.
Business example: Quantity = 5 and Unit Price = 12,000. Excel calculates Revenue as 5 × 12,000 = 60,000.
Session 2 • 75 minutes
Relative and Absolute References
Simple story: A relative reference moves when copied. An absolute reference is “locked” and stays fixed.
  1. Put a tax rate of 7.5% in H1.
  2. In F2 type =E2*$H$1.
  3. Copy the formula down.
  4. Click different tax cells and observe that E2 changes to E3, E4, etc., but $H$1 stays fixed.
Practice: Put a discount rate in another cell and calculate Discount Amount for all transactions using an absolute reference.
Common mistake: Writing =E2*H1 and copying down will change H1 to H2, H3, H4. This gives wrong results if the tax rate exists only in H1.

Logical, Conditional & Lookup Functions

Answer business questions with criteria and bring information from other tables.

Analysis Functions

1. IF & Logical Thinking

  • =IF(test, value_if_true, value_if_false)
  • Example: =IF(H2>=100000,"Target Met","Below Target").
  • Use AND and OR when more than one condition is needed.
  • Understand simple nested IF, but avoid unnecessarily complex nesting.

2. Conditional Aggregations

  • SUMIF and SUMIFS.
  • COUNTIF and COUNTIFS.
  • AVERAGEIF and AVERAGEIFS.
  • Example: total sales for one region or one product category.

3. Lookup Functions

  • Understand why lookup tables are used.
  • Use XLOOKUP where available.
  • Understand VLOOKUP for older versions.
  • Know exact match vs approximate match.
  • Use IFERROR to display a friendly result when a lookup fails.

4. Text & Date Helpers

  • LEFT, RIGHT, MID, LEN, CONCAT/TEXTJOIN.
  • YEAR, MONTH, DAY, TODAY.
  • Use TEXT when a custom display is needed.
  • Create Month or Year helper columns for analysis.

🎯 Week Goal

Use business rules, criteria, and lookup tables to enrich and summarize your data.

Detailed Learning Sessions

Week 4 teaches Excel to make decisions, calculate with conditions, and retrieve information from another table.

Session 1 • 75 minutes
IF, AND and OR
Explain it simply: IF asks a question. If the answer is true, Excel returns one result. If false, it returns another.
Example: =IF(E2>=100000,"High Value","Regular")
If Revenue is at least 100,000, the order is labelled High Value; otherwise it is Regular.
Add multiple conditions
  • =IF(AND(E2>=100000,F2>=20000),"Excellent","Review")
  • =IF(OR(C2="Lagos",C2="Abuja"),"Priority Market","Other")
Practice: Create a Performance column: Sales >= 500,000 = “Target Met”; otherwise “Below Target”.
Session 2 • 75 minutes
SUMIF/SUMIFS and COUNTIF/COUNTIFS
Simple idea: These functions do a calculation only for rows that meet a condition.
  • Total Lagos revenue: =SUMIF(C:C,"Lagos",E:E)
  • Total Lagos Laptop revenue: =SUMIFS(E:E,C:C,"Lagos",D:D,"Laptop")
  • Count Lagos orders: =COUNTIF(C:C,"Lagos")
  • Count Lagos orders above 100,000: =COUNTIFS(C:C,"Lagos",E:E,">100000")
Watch the ranges: In SUMIFS and COUNTIFS, all ranges should line up row-for-row. Do not use E2:E100 for one range and C2:C50 for another.
Session 3 • 90 minutes
XLOOKUP, VLOOKUP and Error Handling
Story: Imagine the Sales table only has Product ID. The Products table contains Product ID, Product Name, Category and Cost. A lookup finds the Product ID and brings the required information into Sales.
  1. Create a Products table with ProductID, Product, Category, Unit Cost.
  2. In the Sales table, add a Category column.
  3. Use =XLOOKUP([@ProductID],Products[ProductID],Products[Category],"Not Found").
  4. Repeat for Unit Cost.
  5. If XLOOKUP is unavailable, demonstrate VLOOKUP with exact match.
Practice: Add Customer Segment from a Customers table using Customer ID.
End-of-week recap: The learner should be able to classify records with IF, calculate condition-based totals and counts, and retrieve matching information from another table.

Data Cleaning & Preparation

Fix messy data before analysis — one of the most important Excel skills.

Data Quality

1. Identify Common Data Problems

  • Blank rows and columns.
  • Duplicate records.
  • Extra spaces.
  • Numbers stored as text.
  • Inconsistent spelling or category labels.
  • Dates stored in inconsistent formats.

2. Cleaning Tools

  • Remove Duplicates.
  • Find & Replace.
  • Text to Columns.
  • TRIM, CLEAN, UPPER, LOWER, PROPER.
  • Convert text numbers to numeric values.

3. Blank & Error Handling

  • Find blanks using filters or Go To Special.
  • Decide whether to fill, remove, or leave blanks.
  • Use IFERROR carefully.
  • Do not replace missing business data with zero unless zero is genuinely correct.

4. Data Structure Rules

  • One header row.
  • One record per row.
  • One field per column.
  • No subtotals inside raw data.
  • No decorative blank rows inside a dataset.
  • Keep source data separate from report output.

🎯 Week Goal

Take a messy sheet and turn it into a consistent, analysis-ready table.

Detailed Learning Sessions

Week 5 is about data quality. Learners should understand that a beautiful dashboard built on dirty data will still be wrong.

Session 1 • 60–75 minutes
Recognising Dirty Data
Explain it simply: Dirty data means the same idea appears in different forms, information is missing, records are repeated, or numbers/dates are stored wrongly.
Examples to show learners
  • Lagos, lagos, LAGOS, Lagos  
  • ₦50,000 stored as text instead of number
  • Duplicate Order IDs
  • 15/08/2026 mixed with “Aug 15, 2026” and text dates
  • Blank Product values
Class activity: Give learners 15 messy records and ask them to identify every problem before they clean anything.
Session 2 • 90 minutes
Cleaning with Built-in Tools and Functions
  1. Use Remove Duplicates and explain which columns determine a true duplicate.
  2. Use Find & Replace to standardize simple text values.
  3. Use =TRIM(A2) to remove unnecessary spaces.
  4. Use =PROPER(A2) for names such as “john ade”.
  5. Use Text to Columns when data such as “Lagos|South” must be split.
  6. Convert text numbers to real numbers.
  7. Check that dates behave like dates by changing their date format.
Important: Do not use Remove Duplicates blindly. Two customers can have the same name and still be different people. Use an appropriate unique identifier where possible.
Session 3 • 60 minutes
Handling Blanks and Creating Analysis-Ready Structure
  1. Filter a column for blanks.
  2. Decide whether each blank should be corrected, left blank, or removed.
  3. Do not replace every blank with zero.
  4. Make sure there is only one header row.
  5. Remove decorative subtotals from raw data.
  6. Keep one record per row and one field per column.
Example: “No sale” can legitimately be zero, but “Unit Cost is unknown” should not automatically become zero because that would distort profit.
End-of-week recap: Learners should be able to inspect a dataset, explain what is wrong, clean it carefully, and leave it in a simple rectangular table ready for analysis.

Charts & Data Visualization

Choose the right visual for the question and make charts easy to understand.

Visualization

1. Choose the Right Chart

  • Column/Bar: compare categories.
  • Line: show trends over time.
  • Pie/Donut: simple part-to-whole with few categories only.
  • Scatter: compare two numerical variables.
  • Combo: compare measures with different scales or add a target line.

2. Chart Formatting

  • Use a clear chart title.
  • Remove unnecessary gridlines and borders.
  • Use data labels only when helpful.
  • Format axes and number units.
  • Keep colours consistent and purposeful.
  • Avoid 3D charts for normal business reporting.

3. Build KPI Cards

  • Display Total Revenue, Total Profit, Margin %, Orders.
  • Use large, clear numbers.
  • Use linked cells or shapes for presentation.
  • Use sensible number formats such as £1.2M or ₦850K where appropriate.

4. Visual Storytelling

  • Every chart should answer a question.
  • Put important visuals at the top or left.
  • Use titles that communicate meaning, not only field names.
  • Use whitespace to separate sections.
