Module-by-module study plan

Open any module to return directly to its lesson.

  1. MODULE 01AI literacy, analytics tasks and limitsSeparate a model-written suggestion from a verified dataset calculation in a side-by-side comparison.
  2. MODULE 02Prompt engineering as a mini specificationWrite a prompt specifying dataset, row grain, metric rules, output and validation tests.
  3. MODULE 03Privacy, safety and responsible AICreate a simple classification of information that must not be pasted into hosted services.
  4. MODULE 04AI-supported Excel and Power QueryAsk for an Excel formula (or draft it yourself), then test returned rows, blanks and totals.
  5. MODULE 05AI-assisted SQL with schema-grounded outputReview a generated SQLite query against actual schema; execute and compare to a manual control.
  6. MODULE 06AI-assisted Python and debuggingRequest or write Python code and keep the failing test and corrected test outcome.
  7. MODULE 07AI-assisted DAX and semantic modelsTest a DAX measure under West-only and all-region contexts; record assumptions.
  8. MODULE 08Statistical reasoning, ML and forecast critiqueCritique an unsupported causal or forecast claim using the six-order sample limitations.
  9. MODULE 09Automation, agents and human approvalDesign a workflow with human approval, safe inputs, retry behavior and an audit trail.
  10. MODULE 10Governed AI analytics capstoneDeliver prompts, model/context disclosure if used, manual baseline, validation evidence and caveats.

Prepare for this course

COURSE BRIEF · AI Integration in Data Analysis

Learn it, verify it, use it

Who it is for: Analysts who want to use AI thoughtfully without treating generated text or code as verified evidence.

Before you begin: Introduction to Data Analysis; spreadsheet/SQL/Python examples assume the corresponding lesson has been reviewed.

Setup and limitations: An AI API account is optional. The course is executable with the offline/reference materials and manual alternatives. Never upload real personal or confidential data to a model without permission. Any hosted AI product, model, feature or free plan may change.

Suggested commitment: Suggested study plan: 2–4 hours per module over 10 modules; AI subscriptions are not required.

By the end: Produce an AI-assisted analysis with a documented prompt log, a manual baseline, executed tests, privacy assessment and human sign-off.
