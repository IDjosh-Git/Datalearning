Curriculum extension · practical proficiency

Applied mastery: Introduction

Work through the units in order. Each includes a measurable objective, realistic case, reproducible example and an evidence-based checkpoint. These supplemental exercises do not replace the existing quizzes or graded progress.

Applied unit 1

Understand the analytics lifecycle

Learning objectives

Describe a business question, data collection, cleaning, analysis, visualization, and communication.

Workplace use case

Investigate a decline in monthly sales with a simple question tree.

Guided practice

  1. Define metric
  2. identify grain
  3. request source tables
  4. check quality
  5. compute baseline
  6. summarize.

Worked example

Question → Metric → Source → Quality check → Analysis → Decision

Assessment checkpoint

Which questions must be resolved before analyzing a sales decline? Propose three diagnostic hypotheses.

Applied unit 2

Recognize data types and quality issues

Learning objectives

Distinguish categorical/numeric, discrete/continuous, dates, IDs, nulls, and duplicates.

Workplace use case

Profile a 100-row store transaction dataset.

Guided practice

  1. List each field
  2. determine type and expected range
  3. inspect duplicates
  4. flag missing values
  5. document fixes.

Worked example

order_id: text (identifier)
order_date: date
amount: decimal currency
channel: category

Assessment checkpoint

Explain why a postal code must not be averaged; identify a missing-value handling policy.

Applied unit 3

Choose the right analytical method

Learning objectives

Match descriptive, diagnostic, predictive, and prescriptive analysis to decisions.

Workplace use case

Present a one-page report recommending an inventory adjustment.

Guided practice

  1. Clarify stakeholder
  2. calculate trend
  3. segment by product
  4. visualize variance
  5. state limitations and next action.

Worked example

Finding: returns rose 6 percentage points.
Evidence: weekly rates by product.
Action: investigate affected supplier batches.

Assessment checkpoint

Write a three-sentence evidence-based recommendation, including one uncertainty.
