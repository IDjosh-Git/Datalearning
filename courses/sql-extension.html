Applied unit 1

Query trustworthy records

Learning objectives

Understand keys, nulls, filters, and joins; explain why row counts change.

Workplace use case

Investigate orders and customers while preserving unmatched records.

Guided practice

  1. Profile tables
  2. SELECT filtered columns
  3. LEFT JOIN on customer_id
  4. COUNT rows before and after.

Worked example

SELECT o.order_id, c.customer_name
FROM orders AS o
LEFT JOIN customers AS c ON c.customer_id = o.customer_id
WHERE o.order_date >= '2026-01-01';

Assessment checkpoint

What is the difference between WHERE and ON for an outer join? Provide a row-count comparison.

Applied unit 2

Aggregate and validate metrics

Learning objectives

Group by useful dimensions; calculate revenue; handle nulls and divide-by-zero safely.

Workplace use case

Find the top five product categories by realized revenue.

Guided practice

  1. Check order status
  2. join order_items
  3. aggregate with SUM
  4. sort
  5. compare with raw transactions.

Worked example

SELECT category, SUM(quantity * unit_price) AS revenue
FROM order_items
WHERE status = 'completed'
GROUP BY category
ORDER BY revenue DESC
LIMIT 5;

Assessment checkpoint

Explain why grouping by category does not guarantee unique transaction counts.

Applied unit 3

Analyze patterns with windows

Learning objectives

Use CTEs, ROW_NUMBER, and running totals without collapsing detail.

Workplace use case

Rank monthly customer revenue and identify repeat purchasers.

Guided practice

  1. Create monthly CTE
  2. sum revenue per customer
  3. window-rank within each month
  4. inspect ties.

Worked example

WITH monthly AS (
 SELECT customer_id, DATE_TRUNC('month',order_date) AS month, SUM(total) AS revenue
 FROM orders GROUP BY 1,2
) SELECT *, DENSE_RANK() OVER (PARTITION BY month ORDER BY revenue DESC) AS rank_in_month FROM monthly;

Assessment checkpoint

When should you use DENSE_RANK rather than ROW_NUMBER? Provide an example with tied revenue.
