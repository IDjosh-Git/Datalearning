Curriculum extension · practical proficiency

Applied mastery: Excel

Work through the units in order. Each includes a measurable objective, realistic case, reproducible example and an evidence-based checkpoint. These supplemental exercises do not replace the existing quizzes or graded progress.

Applied unit 1

Clean and validate real data

Learning objectives

Identify numeric, text, and date types; detect blank cells and duplicates; validate a prepared table.

Workplace use case

Import a sales CSV, convert it into a Table, and add controlled status choices.

Guided practice

  1. Select the range
  2. Ctrl+T
  3. inspect data types
  4. Data Validation
  5. remove duplicates after reviewing keys.

Worked example

=IF(OR([@Quantity]="",[@UnitPrice]=""),"Review",[@Quantity]*[@UnitPrice])

Assessment checkpoint

Why should an ID column be treated as text when leading zeros matter? Export a validated sales table and note three defects fixed.

Applied unit 2

Analyze sales performance

Learning objectives

Use SUMIFS and COUNTIFS with criteria; distinguish revenue from profit; reconcile totals.

Workplace use case

Build a monthly revenue report by product and sales representative.

Guided practice

  1. Add Revenue and Cost columns
  2. calculate Profit
  3. SUMIFS by month and rep
  4. cross-check the grand total.

Worked example

=SUMIFS(Sales[Revenue],Sales[Rep],A2,Sales[Month],B2)

Assessment checkpoint

Explain why summing a subtotal alongside its underlying rows double-counts revenue. Submit a reconciliation check.

Applied unit 3

Communicate with an interactive dashboard

Learning objectives

Create PivotTables, slicers, meaningful KPIs, and accessible chart labels.

Workplace use case

Build an executive sales dashboard with Revenue, Gross Profit, and Gross Margin.

Guided practice

  1. Insert PivotTable
  2. group by month
  3. add slicers
  4. design a KPI panel
  5. test slicer interactions.

Worked example

=IFERROR(SUM(Sales[Profit])/SUM(Sales[Revenue]),0)

Assessment checkpoint

Filter to one product and verify every KPI changes coherently. Include accessible chart titles.
