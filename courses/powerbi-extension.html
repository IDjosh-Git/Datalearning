Curriculum extension · practical proficiency

Applied mastery: Powerbi

Work through the units in order. Each includes a measurable objective, realistic case, reproducible example and an evidence-based checkpoint. These supplemental exercises do not replace the existing quizzes or graded progress.

Applied unit 1

Build a reliable semantic model

Learning objectives

Explain fact/dimension tables, cardinality, filter direction, and a date dimension.

Workplace use case

Model sales, products, customers, and a calendar.

Guided practice

  1. Load and type tables in Power Query
  2. remove duplicates in dimensions
  3. create relationships
  4. validate filters.

Worked example

Revenue = SUMX(Sales, Sales[Quantity] * Sales[Unit Price])

Assessment checkpoint

Why is a star schema preferable to indiscriminate bidirectional filtering? Draw relationships.

Applied unit 2

Write context-aware DAX

Learning objectives

Distinguish measures from calculated columns and understand filter context.

Workplace use case

Calculate year-to-date revenue and profit margin under slicers.

Guided practice

  1. Create base measures
  2. add a marked Date table
  3. test CALCULATE and DATESYTD
  4. inspect totals.

Worked example

Revenue YTD = CALCULATE([Revenue], DATESYTD('Date'[Date]))
Profit Margin = DIVIDE([Profit], [Revenue])

Assessment checkpoint

Explain why DIVIDE is safer than / for an empty denominator; compare two slicer states.

Applied unit 3

Deliver an accessible report

Learning objectives

Use visual hierarchy, descriptive alt text, drillthrough, and conditional formatting.

Workplace use case

Build a sales overview with category breakdown and trend analysis.

Guided practice

  1. Sketch questions
  2. select appropriate visuals
  3. add report-page tooltips
  4. inspect tab order
  5. verify contrast.

Worked example

Variance % = DIVIDE([Actual] - [Plan], [Plan])

Assessment checkpoint

Prove all key measures respect product and date slicers; describe the visual insights in text.
