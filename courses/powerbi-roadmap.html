Module-by-module study plan

Open any module to return directly to its lesson.

  1. MODULE 01Power BI Desktop and business questionsWrite an audience, question and KPI specification before opening the report canvas.
  2. MODULE 02Power Query M and repeatable cleanupImport six rows and show the transformation steps, date/number types and row-count check.
  3. MODULE 03Star schema and relationshipsConstruct FactSales with unique dimension keys and one-to-many, single-direction relationships.
  4. MODULE 04DAX measures and evaluation contextCreate completed-revenue 578,000 and completed-profit 135,000 measures; test one region selection.
  5. MODULE 05Date tables and time intelligenceUse a contiguous marked date table; confirm February 238,000 and explain missing prior-year values.
  6. MODULE 06Visualization and report UXBuild accessible visuals, including a labelled East-West-North comparison and concise conclusions.
  7. MODULE 07Slicers, drillthrough and navigationVerify West slicer = 190,000; drillthrough and reset preserve the intended filter context.
  8. MODULE 08Intermediate DAX and context controlTest region share and rank with multiple slicer combinations; document denominator behavior.
  9. MODULE 09Power BI Service, sharing and refreshPrepare a secure sharing/refresh checklist; distinguish local report from Service dashboards.
  10. MODULE 10Power BI portfolio capstoneDeliver report file if available, model diagram, measure definitions, validation evidence and accessibility notes.
