Applied unit 1

Build a reproducible data-quality pipeline

Learning objectives

Load a CSV, check row grain, detect nulls and duplicates, and keep an audit trail for corrections.

Workplace use case

A store exports order records daily. The analyst must identify unexpected duplicates and preserve the original file.

Guided practice

  1. Read the source file without altering it.
  2. Assert the expected columns exist.
  3. Count records, nulls and duplicate order IDs.
  4. Write a quality summary; correct only after recording decisions.

Worked example

import pandas as pd
orders = pd.read_csv('mastery_orders.csv')
assert orders['order_id'].is_unique, 'Duplicate order IDs'
print(orders.isna().sum().to_string())

Assessment checkpoint

Explain why deleting every row containing a null can bias revenue reporting. Provide a safer treatment rule and test it.

Applied unit 2

Reconcile KPIs with independent calculations

Learning objectives

Use Boolean filtering and groupby to compute consistent counts, revenue and profit.

Workplace use case

Finance requires region totals that reconcile to a completed-orders report.

Guided practice

  1. Filter to completed orders without modifying the raw table.
  2. Calculate line revenue.
  3. Group by region and produce totals.
  4. Check that regional revenue sums to the overall completed revenue.

Worked example

done = orders.loc[orders['status'].eq('Completed')].copy()
done['revenue'] = done['quantity'] * done['unit_price']
regional = done.groupby('region')['revenue'].sum()
assert regional.sum() == done['revenue'].sum()

Assessment checkpoint

For the shared sample, reconcile completed revenue to 578,000. Explain any mismatch in row grain, status or numeric types.

Applied unit 3

Communicate statistical results responsibly

Learning objectives

Compare mean and median, inspect outliers, and distinguish an observed pattern from a causal claim.

Workplace use case

Managers ask whether a new promotion caused a sales increase using only a few daily observations.

Guided practice

  1. Summarise count, median, mean and variation.
  2. Plot values with accessible labels.
  3. Check for seasonality and missing dates.
  4. Write a recommendation that discloses uncertainty and alternative explanations.

Worked example

summary = done['revenue'].agg(['count', 'mean', 'median'])
print(summary)
# Association alone cannot establish promotion impact.

Assessment checkpoint

Write a three-sentence interpretation of average order value that mentions sample size, outliers, and a follow-up check.

Applied unit 4

Package an auditable analysis deliverable

Learning objectives

Separate source data, reusable functions, validation tests, outputs and README instructions.

Workplace use case

A colleague must rerun your report next month without changing the analysis logic.

Guided practice

  1. Create input, src, tests and output folders.
  2. Write a function for completed revenue.
  3. Add tests for empty data and returned orders.
  4. Document install and run instructions with a sample command.

Worked example

def completed_revenue(df):
    completed = df.loc[df['status'].eq('Completed')]
    return (completed['quantity'] * completed['unit_price']).sum()
assert completed_revenue(orders) == 578000

Assessment checkpoint

Submit a small repository or ZIP containing the code, synthetic data, one test report and a reproducibility checklist.
