Module-by-module study plan

Open any module to return directly to its lesson.

  1. MODULE 01SQL foundations and relational thinkingReturn the three illustrated completed orders, then return all five, preserving a deterministic order.
  2. MODULE 02Filtering, Boolean logic and sortingFilter East and West completed orders worth at least 40,000, and justify the AND/OR grouping.
  3. MODULE 03Aggregations and KPI definitionsReconcile the 3 regional gross-revenue rows to the independent 578,000 control total.
  4. MODULE 04Joins and relationship cardinalityJoin to customers without increasing the five completed orders; document key cardinality.
  5. MODULE 05NULLs, CASE and data qualityClassify returns explicitly and compare COUNT(*) and COUNT(non_null_column) on nullable values.
  6. MODULE 06CTEs and layered SQLBuild a CTE with status filtering before grouping and prove it matches the ungrouped total.
  7. MODULE 07Window functions and rankingShow a deterministic most-recent order per customer; explain ties and ROW_NUMBER.
  8. MODULE 08Date analysis and period-over-period metricsReport January 340,000 and February 238,000 using yyyy-mm keys; compare complete periods only.
  9. MODULE 09Performance and validationRun row-count, key uniqueness and completed-revenue checks before discussing EXPLAIN QUERY PLAN.
  10. MODULE 10SQL analytics capstoneDeliver one SQL script, output tables, a query-validation checklist and a decision narrative.

Prepare for this course

COURSE BRIEF · SQL for Data Analysis

Learn it, verify it, use it

Who it is for: Analysts who need to turn database records into verified answers, not just copy SELECT statements.

Before you begin: Introduction to Data Analysis; familiarity with rows, keys, types and totals.

Setup and limitations: SQLite 3.25+ for these training queries and window functions. Use the included mastery_orders.sqlite. Browser Arena SQL uses its separate challenge database; other SQL engines have different date and LIMIT syntax.

Suggested commitment: Suggested study plan: 2–4 hours per module across 10 modules, allowing extra time for joins and windows.

By the end: Write and explain a repeatable SQLite reporting script with correct grain, joins, dates, totals and quality checks.
