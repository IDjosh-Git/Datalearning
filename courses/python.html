Python setup, files and analyst mindset

By the end, you can: Load a dataset reproducibly and inspect its structure.

01 · The business reason — why this matters

Analysts use Python when work must be repeatable, combine multiple files, or scale beyond manual clicking. The first objective is a clean, runnable environment.

02 · How it actually works

Python executes statements in order, stores objects in variables, and imports reusable packages. Use a virtual environment, pin dependencies, keep raw files separate, and confirm the working directory before reading CSV data.

03 · Worked example
from pathlib import Path
import pandas as pd
path = Path('mastery_orders.csv')
orders = pd.read_csv(path, parse_dates=['order_date'])
print(orders.shape)
print(orders['status'].value_counts().to_dict())
Expected result / verification
(6, 12)
{'Completed': 5, 'Returned': 1}
💡 Industry pro tip

Use python -m venv .venv and a requirements file. Do not embed credentials in notebooks.

⚠️ Common beginner trap

FileNotFoundError often means the working directory is wrong; inspect Path.cwd() and the path first.

04 · 🚀 Hands-on knowledge check

Try each question before opening the worked solution.

Challenge 1: What does orders.shape report?
Worked solution

The number of rows and columns as a tuple: (6,12) for the supplied file.

Challenge 2: How can you avoid treating dates as arbitrary strings?
Worked solution

Pass parse_dates=['order_date'] in read_csv or validate with pd.to_datetime.

📌 Key takeaways / cheat sheet
  • Create environment → read input → inspect rows/types → validate before transforming.

Variables, types and control flow

By the end, you can: Translate a calculation rule into correct Python logic.

01 · The business reason — why this matters

Reporting calculations rely on precise numeric types and conditions; errors can turn a returned order into recognized sales.

02 · How it actually works

int, float, str, bool and None model different values. Conditions are evaluated before a result is added. Use Decimal when exact decimal-currency arithmetic is required; floats can produce rounding surprises.

03 · Worked example
orders = [
 {'id': 1001, 'qty': 2, 'price': 150000, 'status':'Completed'},
 {'id': 1003, 'qty': 3, 'price': 8000, 'status':'Returned'}
]
value = sum(o['qty'] * o['price']
  for o in orders if o['status']=='Completed')
print(value)
Expected result / verification
300000 (returned order 1003 is excluded).
💡 Industry pro tip

Prefer descriptive variable names and assertions for assumptions, e.g., assert amount >= 0.

⚠️ Common beginner trap

Using = inside a condition is a syntax error; use == for equality. Avoid comparing text values to numbers.

04 · 🚀 Hands-on knowledge check

Try each question before opening the worked solution.

Challenge 1: What is the value of 3 * 8000?
Worked solution

24000, but that returned order does not contribute to completed revenue.

Challenge 2: How would you protect against a missing status value?
Worked solution

Use o.get('status')=='Completed'; absent status fails the inclusion test.

📌 Key takeaways / cheat sheet
  • Types determine valid operations
  • test conditions explicitly
  • keep business rules readable.

MASTERCLASS / MODULE 03 · Python for Data Analytics

Functions, collections and reusable scripts

By the end, you can: Write one calculation once and reuse it safely.

01 · The business reason — why this matters

Analysts often repeat net-sales and margin logic across reports; functions prevent inconsistent copies.

02 · How it actually works

A function receives parameters, evaluates a body, and returns a value. A list keeps ordered records; a dictionary maps named attributes. Type hints communicate contracts but do not validate values at runtime.

03 · Worked example
def revenue(quantity: int, unit_price: float) -> float:
    if quantity < 0 or unit_price < 0:
        raise ValueError('Negative input is not expected')
    return quantity * unit_price
print(revenue(2, 150000))
print(revenue(5, 8000))
Expected result / verification
300000
40000
💡 Industry pro tip

Keep business rules in tested functions; keep file input/output at the edges of the script.

⚠️ Common beginner trap

Mutable default arguments such as def f(items=[]) can leak state between calls.

04 · 🚀 Hands-on knowledge check

Try each question before opening the worked solution.

Challenge 1: Why return instead of only print?
Worked solution

Returned values can be reused in calculations, unit tests and reports.

Challenge 2: What happens with revenue(-1,8000)?
Worked solution

It raises ValueError because the function rejects unexpected negative quantities.

📌 Key takeaways / cheat sheet
  • Small functions are easier to test
  • keep inputs explicit and outputs predictable.

MASTERCLASS / MODULE 04 · Python for Data Analytics

pandas selection and filtering

By the end, you can: Filter the correct transactions before aggregation.

01 · The business reason — why this matters

A pandas DataFrame brings SQL-like filtering to CSV data, allowing consistent calculations in automated pipelines.

02 · How it actually works

A DataFrame is a two-dimensional labelled table. A Boolean mask marks eligible rows; .loc selects rows and columns by labels. Vectorised operations generally avoid slow Python-level iteration.

03 · Worked example
import pandas as pd
df = pd.read_csv('mastery_orders.csv')
completed = df.loc[df['status'].eq('Completed')].copy()
completed['revenue'] = completed['quantity'] * completed['unit_price']
print(len(completed), int(completed['revenue'].sum()))
Expected result / verification
5 578000
💡 Industry pro tip

Use .loc and .copy() when creating a filtered DataFrame to make intent explicit.

⚠️ Common beginner trap

Do not use `and` between pandas Series masks; use `&` with parentheses: (a) & (b).

04 · 🚀 Hands-on knowledge check

Try each question before opening the worked solution.

Challenge 1: How many rows qualify as Completed?
Worked solution

5; returned order 1003 is excluded by the Boolean mask.

Challenge 2: How do you select just East completed orders?
Worked solution

df.loc[df['status'].eq('Completed') & df['region'].eq('East')] returns orders 1001 and 1006.

📌 Key takeaways / cheat sheet
  • Filter using Boolean masks
  • vectorize arithmetic
  • validate row counts.

MASTERCLASS / MODULE 05 · Python for Data Analytics

Cleaning, nulls, typing and joins

By the end, you can: Protect an analytics pipeline against faulty imports.

01 · The business reason — why this matters

Noisy files often carry blank customer IDs, mixed formats and duplicate keys. Failures should be reported, not silently discarded.

02 · How it actually works

Use .isna() for NULL checks, .duplicated() for repeated keys and .merge(validate=...) to enforce join cardinality. Convert types deliberately with pd.to_numeric and pd.to_datetime; coerce errors only when you keep an exception count.

03 · Worked example
import pandas as pd
df = pd.read_csv('mastery_orders.csv')
print(int(df['order_id'].duplicated().sum()))
print(int(df['customer_id'].isna().sum()))
assert df['order_id'].is_unique
assert df['quantity'].ge(0).all()
Expected result / verification
0 duplicate OrderIDs
0 missing customer IDs
Assertions pass for the training file.
💡 Industry pro tip

Check duplicates and missing IDs both before and after merges; use validate="many_to_one" for fact→dimension lookups.

⚠️ Common beginner trap

A merge on duplicate lookup keys can multiply transaction rows and inflate sales.

04 · 🚀 Hands-on knowledge check

Try each question before opening the worked solution.

Challenge 1: What does validate="many_to_one" mean?
Worked solution

Many fact rows can match one dimension key, but the dimension key must be unique.

Challenge 2: When should to_numeric(errors="coerce") be used?
Worked solution

Only alongside a review of rows converted to NaN, not as a silent data-loss shortcut.

📌 Key takeaways / cheat sheet
  • Validate keys, types and joins
  • produce an exception report alongside cleaned data.

MASTERCLASS / MODULE 06 · Python for Data Analytics

groupby, pivot and business KPI reporting

By the end, you can: Generate a clear, reproducible regional summary.

01 · The business reason — why this matters

An automated weekly report needs the same measure definitions as the SQL and Power BI versions.

02 · How it actually works

groupby creates category partitions and reduces each to aggregations. Avoid adding percentages as if they were additive measures; compute a ratio from aggregated numerator and denominator.

03 · Worked example
import pandas as pd
df = pd.read_csv('mastery_orders.csv')
x = df.loc[df.status.eq('Completed')].copy()
x['revenue'] = x.quantity * x.unit_price
print(x.groupby('region')['revenue'].sum().sort_values(ascending=False).to_dict())
Expected result / verification
{'East': 316000, 'West': 190000, 'North': 72000}
💡 Industry pro tip

Use named aggregation and unit-tested metric functions in production reporting code.

⚠️ Common beginner trap

groupby drops NULL grouping keys by default in pandas unless dropna=False is specified.

04 · 🚀 Hands-on knowledge check

Try each question before opening the worked solution.

Challenge 1: How do you calculate completed profit?
Worked solution

Create x['profit']=x.quantity*(x.unit_price-x.unit_cost), then sum: 135000.

Challenge 2: How do you confirm the regional totals?
Worked solution

Sum regional revenue totals; the result must equal 578000.

📌 Key takeaways / cheat sheet
  • Filter correctly
  • group at the business grain
  • reconcile grouped sums.

MASTERCLASS / MODULE 07 · Python for Data Analytics

Statistics and uncertainty

By the end, you can: Interpret metrics without making unsupported causal claims.

01 · The business reason — why this matters

Executives often ask whether an apparent change reflects a durable pattern or random variation; statistics clarify what data can and cannot establish.

02 · How it actually works

Mean is sum/count, median is the middle observation after sorting, standard deviation measures variation, and sampling affects uncertainty. Correlation describes association, not proof of causation. Six fabricated rows are useful for learning syntax, not inference.

03 · Worked example
values = [300000,40000,72000,150000,16000]
import statistics as stats
print(stats.mean(values))
print(stats.median(values))
print(min(values), max(values))
Expected result / verification
115600
72000
16000 300000
💡 Industry pro tip

Communicate sample size, metric definition and any selection bias alongside a summary.

⚠️ Common beginner trap

Using the mean as a typical order is misleading when there is a large 300000 order; compare median.

04 · 🚀 Hands-on knowledge check

Try each question before opening the worked solution.

Challenge 1: Which statistic is more resistant to outliers?
Worked solution

Median: 72000 in this five-order completed sample.

Challenge 2: Can you infer nationwide sales growth from these six rows?
Worked solution

No. The dataset is intentionally illustrative and not a representative population sample.

📌 Key takeaways / cheat sheet
  • Describe distributions and limitations
  • avoid unsupported causal or population claims.

MASTERCLASS / MODULE 08 · Python for Data Analytics

NumPy vectors and matrix intuition

By the end, you can: Recognize vectorized calculations and matrix dimensions.

01 · The business reason — why this matters

Forecasting and machine learning depend on efficient numeric arrays; matrix dimensions explain common shape errors.

02 · How it actually works

A vector is an ordered numeric array; a matrix has rows and columns. Elementwise multiplication pairs corresponding positions; dot products sum pairwise products. A feature matrix X commonly has rows=observations and columns=features.

03 · Worked example
import numpy as np
qty = np.array([2,5,4])
price = np.array([150000,8000,18000])
print((qty*price).tolist())
print(int(qty @ price))
print(np.column_stack([qty,price]).shape)
Expected result / verification
[300000, 40000, 72000]
412000
(3, 2)
💡 Industry pro tip

Vectorise calculations where possible, but confirm array alignment and units before trusting speed gains.

⚠️ Common beginner trap

Broadcasting may silently stretch arrays; use shape checks instead of relying on assumptions.

04 · 🚀 Hands-on knowledge check

Try each question before opening the worked solution.

Challenge 1: What does an array shape of (3,2) mean?
Worked solution

Three observations and two numeric features per observation.

Challenge 2: What is the dot product of qty and price?
Worked solution

412000, the sum of the three example line revenues.

📌 Key takeaways / cheat sheet
  • Array shape matters
  • multiply elementwise for row totals
  • dot product sums them.

MASTERCLASS / MODULE 09 · Python for Data Analytics

Time series, charts and testable forecasts

By the end, you can: Create a baseline with transparent limitations.

01 · The business reason — why this matters

Forecasting decisions require a benchmark and careful time-aware validation, rather than presenting a clever model as automatically accurate.

02 · How it actually works

Group by chronological month, create a baseline such as previous-month value, and compare predicted vs actual on later unseen periods. Data leakage occurs when future observations enter training features or preprocessing.

03 · Worked example
import pandas as pd
df = pd.read_csv('mastery_orders.csv',parse_dates=['order_date'])
x = df[df.status.eq('Completed')].copy()
x['revenue'] = x.quantity*x.unit_price
monthly = x.groupby(x.order_date.dt.to_period('M'))['revenue'].sum()
print(monthly.to_dict())
Expected result / verification
{Period('2026-01', 'M'): 340000, Period('2026-02', 'M'): 238000}
💡 Industry pro tip

For a real forecast, gather many more periods, define a holdout window and compare against a naive baseline.

⚠️ Common beginner trap

Two months cannot support a reliable seasonal forecast; never advertise predictive accuracy from this demo.

04 · 🚀 Hands-on knowledge check

Try each question before opening the worked solution.

Challenge 1: What is the naive forecast for February based on January?
Worked solution

340000, the previous-month completed revenue.

Challenge 2: What is the February absolute forecast error for that baseline?
Worked solution

abs(238000-340000)=102000.

📌 Key takeaways / cheat sheet
  • Time-aware splits prevent leakage
  • compare with a baseline
  • disclose uncertainty.

MASTERCLASS / MODULE 10 · Python for Data Analytics

Python analytics capstone

By the end, you can: Package a repeatable, independently verified report.

01 · The business reason — why this matters

Professional scripts deliver a consistent output and clear failure messages when inputs change.

02 · How it actually works

Use functions for load, validate, transform, aggregate and export. Include small unit tests, fixed dependency versions, a README and documented schema. Reconcile totals against the SQL workbook control.

03 · Worked example
import pandas as pd
df = pd.read_csv('mastery_orders.csv')
assert df.order_id.is_unique
x = df[df.status.eq('Completed')].copy()
x['revenue']=x.quantity*x.unit_price
x['profit']=x.quantity*(x.unit_price-x.unit_cost)
summary = x.groupby('region')[['revenue','profit']].sum()
assert x.revenue.sum()==578000
assert x.profit.sum()==135000
print(summary.loc['East'].to_dict())
Expected result / verification
{'revenue': 316000, 'profit': 66000}
💡 Industry pro tip

Add automated test cases for empty data, missing required fields and duplicate identifiers.

⚠️ Common beginner trap

Notebook outputs saved after a different execution order are not proof of reproducibility; run from a clean kernel.

Try each question before opening the worked solution.

Worked solution

Challenge 2: What should the README specify?
Worked solution

How to install, where to place input files, expected schema, run command, metric definitions and known limitations.

📌 Key takeaways / cheat sheet
  • Package source + tests + readme + validated outputs, not only notebook screenshots.
