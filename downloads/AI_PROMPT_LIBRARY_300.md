# Complete AI Prompt Library — 300 prompts

An offline companion to the searchable `prompt-library.html` page. The prompts use fictional dataset context and bracketed fields to customize. Do not paste confidential information into unauthorized AI services. All generated formulas or conclusions must be independently tested.

## How to personalize

Replace `[PASTE COLUMN NAMES AND TYPES HERE]` with your actual approved schema. Replace `[INSERT THE QUESTION, DATE RANGE, FILTERS AND EXCLUSIONS]` with an unambiguous business problem and metric rules. Run the generated work in Excel, SQL, Python or Power BI; document errors, corrections and independent checks.
