# AI in Data Analysis — Plain-Language Glossary

These terms support the 10-week AI Integration course and the other data analysis tracks. Examples use the fictional retail dataset unless stated.

### API

An interface through which software systems exchange requests and responses.

### Accuracy

How close a reported value is to the defined correct value. Verify against source records and independent calculations.

### Agent

An AI-powered workflow that can select or perform actions using tools; access should be limited and actions audited.

### Aggregation

Combining detailed records into a metric such as count, sum or average at a specified grain.

### Anonymization

Removing personal identifiers sufficiently to prevent identification, considering indirect linkage risks.

### Assumption

A rule accepted for an analysis (for example, blank discount means zero); it must be stated, tested and approved.

### AutoML

Tools that automate parts of model training, tuning and evaluation; their outputs still require validation.

### Baseline

A simple method used to compare against a more complex analytical approach or forecast.

### Bias

Systematic distortion caused by data coverage, labels, collection, modeling or interpretation.

### Business question

The decision and measurable problem the analysis must support.

### Cardinality

How table records relate, such as one-to-one or one-to-many; wrong joins can multiply measures.

### Classification

Prediction of a category, such as whether an order might be returned.

### Cloud sync

Saving learning progress across signed-in devices using the configured backend service.

### Confounding

A third factor that affects both variables and can create a misleading apparent relationship.

### Correlation

A statistical association; it does not alone establish causation.

### DAX

Data Analysis Expressions: formula language for measures and other calculations in Power BI.

### Data dictionary

The definitions, types, allowed values, units and meaning of fields in a dataset.

### Data leakage

Using information during model training that would not be available at the real prediction time.

### Data lineage

The recorded chain from source records through transformations to an output or report.

### Data minimization

Using or sharing only data fields actually needed for an approved task.

### Deterministic calculation

An operation that produces the same result for the same inputs and rules, such as an Excel formula or SQL query.

### Drift

A material change in source patterns or model performance over time.

### ETL

Extract, Transform, Load: acquiring, preparing and loading data.

### Evaluation metric

A numerical criterion such as MAE, RMSE or precision for judging model quality.

### Exploratory data analysis

Investigating structure, missingness, distributions and relationships before formal conclusions.

### Feature

An input variable available to a prediction model.

### Filter context

The filters active when a DAX measure evaluates, including slicers and relationships.

### Forecasting

Estimating a future value based on past information and a stated model.

### Generative AI

Systems that produce content such as prose, code or images from learned patterns and prompt context.

### Grain

What one record in a table represents, such as one order line or one region-month target.

### Grounding

Anchoring a statement or model response in known sources or executed computations.

### Hallucination

An unsupported or fabricated claim generated by an AI system.

### Holdout set

Data withheld from model fitting and used to assess performance on unseen cases.

### Human-in-the-loop

A workflow where an authorized person checks, approves or rejects important outputs or actions.

### Inference

Applying a trained model to new inputs to generate a prediction or response.

### Join fanout

When a join increases the number of records because the key is not unique on the intended side.

### KPI

Key performance indicator, a defined measure of business performance.

### LLM

Large language model, an AI model that predicts and generates text tokens.

### MAE

Mean absolute error: the average absolute difference between actual and predicted values.

### Measure

A reusable calculation evaluated under current filter context in a BI model.

### Metric definition

The exact formula, filters, grain, time period and exclusions used for a business figure.

### MoM

Month-over-month comparison, often percentage change against a previous month.

### Model card

A short document listing a model’s intended uses, data, evaluation, assumptions and limitations.

### Natural language prompt

Instructions or questions typed in ordinary language to an AI assistant.

### Overfitting

When a model learns noise in training data and performs poorly on fresh data.

### PII

Personally identifiable information such as an email or a combination of identifying attributes.

### Power Query M

Language for repeatable data transformations in Excel and Power BI.

### Precision

For predicted positive cases, the proportion that are actually positive.

### Prediction interval

A range describing uncertainty for a future observation under a model.

### Prompt engineering

Designing AI instructions with clear context, tasks, constraints, output requirements and tests.

### Prompt injection

Instructions embedded in untrusted data attempting to override a system’s intended directions.

### Pseudonymization

Replacing direct identifiers with codes while potentially retaining re-identification possibilities.

### RAG

Retrieval-augmented generation: consulting retrieved material to help form a response; sources still need verification.

### RMSE

Root mean squared error, which penalizes larger prediction errors more heavily than MAE.

### Recall

Among actual positive cases, the proportion identified as positive.

### Reconciliation

Checking that two appropriately comparable calculations agree and investigating discrepancies.

### Regression

Prediction of a continuous quantity, such as future monthly revenue.

### Row context

In DAX, the current row being evaluated by an iterator or calculated column.

### Row-level security

Restricting which rows a particular user is permitted to see in a dataset or report.

### SQL dialect

A database-specific variety of SQL; date and string functions may differ.

### Schema

The tables, column names, data types and relationships of a data model.

### Star schema

A BI model separating measured events (facts) from descriptive dimensions.

### Synthetic data

Invented information used for demonstration that is not genuine personal or confidential information.

### Target leakage

A kind of data leakage where the prediction inputs reveal the future outcome.

### Time series

Observations ordered in time, often analyzed for trend, seasonality and forecasting.

### Unit test

A repeatable test that checks a small piece of code or a calculation against expected values.

### Validation set

Data used during model development to tune or select approaches without relying on the final test set.
